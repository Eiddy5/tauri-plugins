# Screenshot

Tauri 2 原生区域截图插件。调用后冻结当前虚拟桌面，并显示由系统原生窗口实现的框选浮层；用户确认后，JavaScript API 返回 PNG 字节、图像尺寸和选区坐标。

[JavaScript API Reference](docs/javascript-api.md) · [Permission Reference](permissions/autogenerated/reference.md) · [Example App](examples/tauri-app)

当前版本只提供按需区域截图，不注册全局快捷键，也不包含画笔、矩形、箭头等截图后标注能力。

## Supported Platforms

本插件要求 Rust `1.77.2` 或更高版本，并面向 Tauri 2。

| Platform | Level | Notes |
| --- | --- | --- |
| Windows 10/11 | ✅ | Win32 GDI 捕获，Win32 原生浮层 |
| macOS 15.2+ | ✅ | ScreenCaptureKit 捕获，AppKit `NSPanel` + `NSView` 原生浮层 |
| Linux | ❌ | 返回 `unsupported` |
| Android | ❌ | 返回 `unsupported` |
| iOS | ❌ | 返回 `unsupported` |

插件支持多显示器虚拟桌面，包括副屏位于主屏左侧或上方，以及不同缩放比例的显示器组合。浮层、鼠标事件、选区绘制、放大镜和确认工具条均不依赖 WebView。

## Setup

插件由 Rust Core 和 JavaScript Guest bindings 两部分组成。当前不是 Tauri 官方插件，不能使用 `tauri add screenshot` 自动安装，需要手动完成以下步骤。

### 1. 添加 Rust 依赖

在应用的 `src-tauri/Cargo.toml` 中添加本地插件路径。路径相对于该 `Cargo.toml`：

```toml
[dependencies]
tauri-plugin-screenshot = { path = "../../plugins/tauri-plugin-screenshot" }
```

crate 发布到包仓库后，可改用：

```sh
cargo add tauri-plugin-screenshot
```

### 2. 初始化插件

在 Tauri Builder 中注册插件：

`src-tauri/src/lib.rs`

```rust
#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .plugin(tauri_plugin_screenshot::init())
        .run(tauri::generate_context!())
        .expect("error while running Tauri application");
}
```

### 3. 安装 JavaScript bindings

从应用前端目录安装本地包。只需选择项目正在使用的一个包管理器：

```sh
# pnpm
pnpm add file:../plugins/tauri-plugin-screenshot

# npm
npm install ../plugins/tauri-plugin-screenshot

# Yarn
yarn add file:../plugins/tauri-plugin-screenshot

# Bun
bun add ../plugins/tauri-plugin-screenshot
```

npm 包发布后，可改用包名安装：

```sh
pnpm add tauri-plugin-screenshot-api
```

### 4. 配置权限

因为当前采用手动安装，Tauri CLI 不会自动写入默认权限。将 `screenshot:default` 添加到允许调用截图的 capability：

`src-tauri/capabilities/default.json`

```json
{
  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "default",
  "description": "Capability for the main window",
  "windows": ["main"],
  "permissions": [
    "core:default",
    "screenshot:default"
  ]
}
```

只有列在 `windows` 或 `webviews` 中的窗口可以调用插件。更多背景见 Tauri 的 [Capabilities](https://v2.tauri.app/security/capabilities/) 和 [Plugin Permissions](https://v2.tauri.app/learn/security/using-plugin-permissions/) 文档。

## Usage

### 截取并预览

```ts
import { captureArea } from 'tauri-plugin-screenshot-api'

let previousPreviewUrl: string | undefined

const result = await captureArea()

if (result.status === 'cancelled') {
  console.log('用户取消了截图')
} else {
  if (previousPreviewUrl) URL.revokeObjectURL(previousPreviewUrl)

  const blob = new Blob([result.data], { type: result.mimeType })
  previousPreviewUrl = URL.createObjectURL(blob)

  console.log({
    width: result.width,
    height: result.height,
    region: result.region,
    previewUrl: previousPreviewUrl,
  })
}
```

`captureArea()` 在用户确认或取消前保持 pending。取消属于正常结果，不会抛出异常。

### 设置最小选区

```ts
const result = await captureArea({
  minWidth: 8,
  minHeight: 8,
})
```

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `minWidth` | `number` | `2` | 最小选区宽度，逻辑像素 |
| `minHeight` | `number` | `2` | 最小选区高度，逻辑像素 |

传入值应为非负整数；`0` 会按 `1` 逻辑像素处理。小于最小尺寸的拖动会被视为未完成选择并回到待选状态。

### 处理结果

`captureArea()` 返回一个可辨识联合类型：

```ts
type CaptureResult =
  | {
      status: 'captured'
      mimeType: 'image/png'
      width: number
      height: number
      region: {
        x: number
        y: number
        width: number
        height: number
      }
      data: Uint8Array
    }
  | {
      status: 'cancelled'
    }
```

`width`、`height` 和 `region` 均使用捕获图像中的物理像素。`region` 以整个虚拟桌面截图的左上角为原点，因此即使平台原生坐标为负数，返回的 `x`、`y` 仍是非负偏移。

完整类型与函数签名见 [JavaScript API Reference](docs/javascript-api.md)。

## Screenshot Interaction

- 开始截图时立即冻结当前虚拟桌面，并在光标旁显示十字像素放大镜。
- 尚未拖拽时，鼠标自动高亮最上层窗口；单击可选择整窗。
- 拖动可自由创建选区，支持任意方向框选。
- 拖动过程中，放大镜十字中心对应当前选区右下角，并在屏幕边缘自动换向。
- 松开鼠标后进入二次确认；此时可移动选区或拖动四角调整大小。
- 选区使用绿色实线边框和绿色角点。
- 工具条从左到右依次为取消、重选、确认。
- `Esc` 或鼠标右键取消；`Enter` 或双击选区确认。
- 进入二次确认后隐藏放大镜。
- 同一时间只允许一个截图会话；并发调用会返回 `busy`。
- 截图完成后，插件会尝试将焦点还给发起调用的 WebviewWindow。

浮层绘制在已冻结的桌面图像之上，选区边框、放大镜、遮罩和工具条不会进入最终 PNG。

## Default Permission

`screenshot:default` 允许启动区域截图，并读取用户确认后的 PNG 数据。它包含：

- `screenshot:allow-capture-area`
- `screenshot:allow-take-capture`

公开的 `captureArea()` 会依次调用这两个命令，因此前端使用时需要同时授权。`take_capture` 用于内部读取并消费暂存结果，不建议前端直接调用底层 invoke。

## Permission Table

| Identifier | Description |
| --- | --- |
| `screenshot:allow-capture-area` | 允许启动原生截图会话并返回确认结果的元数据 |
| `screenshot:deny-capture-area` | 拒绝调用 `capture_area` |
| `screenshot:allow-take-capture` | 允许读取一次已确认的 PNG 字节 |
| `screenshot:deny-take-capture` | 拒绝调用 `take_capture` |

完整的自动生成说明见 [Permission Reference](permissions/autogenerated/reference.md)。

## Security

屏幕截图可能包含账号、消息和其他敏感内容。建议只在明确的用户操作之后调用 `captureArea()`，并将 capability 限制到确实需要截图能力的窗口。

插件本身不会把截图写入磁盘、复制到剪贴板或上传到网络。确认后的 PNG 暂存在应用内存中，并由 JavaScript binding 立即一次性读取；读取后的结果会从后端暂存队列移除。后续保存、复制或上传行为由应用自行决定和授权。

## Platform Notes

### macOS

- 首次调用会触发系统“屏幕录制”授权。
- 如果用户拒绝授权，调用返回 `permissionDenied`。可引导用户前往“系统设置 → 隐私与安全性 → 屏幕录制”开启权限。
- macOS 可能要求在授权后重启应用。
- 当前 ScreenCaptureKit 实现运行时要求 macOS 15.2 或更高版本。

### Windows

- Windows 10 和 Windows 11 无需额外的系统录屏授权。
- 捕获和浮层均使用当前桌面会话；服务进程、锁屏桌面或不可交互会话不在支持范围内。

## Errors

插件命令失败时会拒绝 Promise，并返回结构化对象：

```ts
interface ScreenshotError {
  code: ScreenshotErrorCode
  message: string
  recoverable: boolean
}

type ScreenshotErrorCode =
  | 'busy'
  | 'permissionDenied'
  | 'unsupported'
  | 'displayUnavailable'
  | 'captureFailed'
  | 'overlayFailed'
  | 'invalidSelection'
  | 'resultUnavailable'
  | 'internal'
```

| Code | Meaning |
| --- | --- |
| `busy` | 已有截图会话正在进行 |
| `permissionDenied` | 缺少 macOS 屏幕录制权限 |
| `unsupported` | 当前操作系统或系统版本不受支持 |
| `displayUnavailable` | 无法读取显示器或虚拟桌面信息 |
| `captureFailed` | 屏幕捕获、裁剪或 PNG 编码失败 |
| `overlayFailed` | 原生截图浮层创建或运行失败 |
| `invalidSelection` | 选区无法映射到有效图像区域 |
| `resultUnavailable` | PNG 结果不存在、已读取或已过期 |
| `internal` | 其他内部错误 |

`recoverable` 表示用户是否可以在不升级系统或更换平台的情况下重试。用户主动取消截图不会进入错误分支，而是返回 `{ status: 'cancelled' }`。

如果错误来自 Tauri ACL，优先检查调用窗口是否包含在 capability 中，以及 capability 是否包含 `screenshot:default`。
