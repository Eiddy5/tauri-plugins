# Tauri Plugin AI

面向 Tauri 2 桌面应用的 AI 工具框架。通过 `@Module` / `@Tool` 将已有 TypeScript 方法注册为工具，提供应用内调用和本机 MCP 服务，支持普通 TypeScript 与 Angular DI。

[JavaScript API](#javascript-api) · [Permission Reference](permissions/autogenerated/reference.md) · [Example App](examples/tauri-app/README.md) · [Framework Design](docs/ai-framework-design.md)

插件由 Rust Core 和 JavaScript Guest bindings 两部分组成：JS 负责工具声明、实例绑定和方法执行；Rust 负责可信调用入口、权限、Schema 校验、并发、超时和 MCP 协议。当前实现 Tool 能力，Resource / Prompt 尚在设计阶段。

## Supported Platforms

本插件要求 Rust `1.90` 或更高版本，并面向 Tauri 2。Angular 适配的 peer dependency 范围为 `>=20 <23`；仓库示例使用 Angular 21，需要 Node.js `22.12+`。桌面构建还需安装 [Tauri 系统依赖](https://v2.tauri.app/start/prerequisites/)。

| Platform | Level | Notes |
| --- | --- | --- |
| macOS | ✅ | 已验证 Angular 桌面宿主与真实 MCP 调用 |
| Windows | 待验证 | 尚未完成桌面运行验收 |
| Linux | 待验证 | 尚未完成桌面运行验收 |
| Android | ❌ | 当前未提供移动端支持 |
| iOS | ❌ | 当前未提供移动端支持 |

普通浏览器可使用独立的 JS Runtime 调试工具。各项验证的具体范围见[验收记录](docs/verification.md)。

## Setup

本插件采用手动安装，需要同时添加 Rust crate、JavaScript bindings 和 Tauri capability。以下示例假设应用位于 `workspace/my-app`，插件源码位于 `workspace/plugins/tauri-plugin-ai`。

### 1. 添加 Rust 依赖

在应用的 `src-tauri/Cargo.toml` 中添加插件。路径相对于该 `Cargo.toml`：

```toml
[dependencies]
tauri-plugin-ai = { path = "../../plugins/tauri-plugin-ai" }
```

### 2. 初始化插件

在 Tauri Builder 中注册插件：

`src-tauri/src/lib.rs`

```rust
pub fn run() {
    tauri::Builder::default()
        .plugin(tauri_plugin_ai::init())
        .run(tauri::generate_context!())
        .expect("error while running Tauri application");
}
```

`init()` 启用应用内 Runtime。需要开放 MCP 服务时，使用下文的 [MCP 配置](#mcp)。

### 3. 安装 JavaScript bindings

先在插件根目录安装依赖并构建 bindings：

```sh
yarn install
yarn build
```

再从应用前端目录安装本地包。选择项目正在使用的一个包管理器：

```sh
# pnpm
pnpm add file:../plugins/tauri-plugin-ai

# npm
npm install ../plugins/tauri-plugin-ai

# Yarn 4：直接链接源码目录
yarn add tauri-plugin-ai-api@portal:../plugins/tauri-plugin-ai
```

Rust crate 和 npm 包发布后，可改用包名安装：

```sh
cargo add tauri-plugin-ai
npm install tauri-plugin-ai-api
```

### 4. 配置权限

将 `ai:runtime` 添加到承载工具执行实例的可信前端 capability：

`src-tauri/capabilities/default.json`

```json
{
  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "default",
  "description": "Capability for the trusted application frontend",
  "windows": ["main"],
  "permissions": [
    "core:default",
    "ai:runtime"
  ]
}
```

`ai:default` 不授予命令权限，需要显式启用 `ai:runtime`。这里的 `windows` 是 Tauri IPC 访问控制；工具通过模块命名空间注册。更多背景见 Tauri 的 [Capabilities](https://v2.tauri.app/security/capabilities/) 和 [Using Plugin Permissions](https://v2.tauri.app/learn/security/using-plugin-permissions/)。

### 5. 配置 TypeScript 与 CSP

装饰器使用 legacy TypeScript decorators，在前端 `tsconfig.json` 中启用：

```json
{
  "compilerOptions": {
    "experimentalDecorators": true
  }
}
```

当前 JS 校验器使用 Ajv 在运行时编译 Schema。若应用启用了 CSP，需在已有 `script-src` 中允许 `'unsafe-eval'`。完整配置见[示例 tauri.conf.json](examples/tauri-app/src-tauri/tauri.conf.json)。构建期 Schema 预编译尚未实现，当前版本无法在禁止动态求值的 CSP 下使用。

## Usage

### 声明工具

`@Module` 声明命名空间，`@Tool` 声明方法契约。输入、输出都必须是 JSON object，并分别提供 JSON Schema 2020-12。

`math-tools.ts`

```ts
import { Module, Tool } from 'tauri-plugin-ai-api'

@Module('math')
export class MathTools {
  @Tool({
    name: 'add',
    description: '将两个数相加',
    inputSchema: {
      type: 'object',
      properties: { a: { type: 'number' }, b: { type: 'number' } },
      required: ['a', 'b'],
      additionalProperties: false,
    },
    outputSchema: {
      type: 'object',
      properties: { sum: { type: 'number' } },
      required: ['sum'],
      additionalProperties: false,
    },
    annotations: {
      readOnlyHint: true,
      destructiveHint: false,
      idempotentHint: true,
      openWorldHint: false,
    },
  })
  add({ a, b }: { a: number; b: number }) {
    return { sum: a + b }
  }
}
```

该方法注册后的工具名为 `math.add`。不使用装饰器时，也可通过 `defineTool({ ...定义, handler })` 创建工具，再交给 `runtime.register()`。

### 普通 TypeScript 接入

在应用启动时注册实例，并显式选择桌面传输：

```ts
import { AiRuntime } from 'tauri-plugin-ai-api'
import { TauriTransport } from 'tauri-plugin-ai-api/tauri'
import { MathTools } from './math-tools'

const runtime = new AiRuntime({ transport: new TauriTransport() })
runtime.registerModule(new MathTools())
await runtime.start()

const result = await runtime.invoke('math.add', { a: 21, b: 21 })
console.log(result) // { sum: 42 }
```

工具必须在 `start()` 前注册。`start()` 完成工具注册和就绪确认后返回；在应用销毁时调用 `await runtime.stop()`。追加工具需要先停止 Runtime，再注册并启动。

纯浏览器调试时，使用 `new AiRuntime()` 即选择 `BrowserTransport`。桌面模式中的应用内调用和 MCP 调用都经过 Rust Runtime；浏览器模式执行 JS 方法，不提供 MCP HTTP 服务。

### Angular 接入

复用前面的 `MathTools`，在 Angular 启动配置中提供实例及 Runtime：

`main.ts`

```ts
import { bootstrapApplication } from '@angular/platform-browser'
import { provideAiRuntime } from 'tauri-plugin-ai-api/angular'
import { TauriTransport } from 'tauri-plugin-ai-api/tauri'
import { AppComponent } from './app'
import { MathTools } from './math-tools'

bootstrapApplication(AppComponent, {
  providers: [
    { provide: MathTools, useFactory: () => new MathTools() },
    provideAiRuntime({
      modules: [MathTools],
      transport: new TauriTransport(),
    }),
  ],
})
```

适配层从 Angular DI 获取已有实例，在应用初始化时启动 Runtime，销毁时停止。组件可通过 `inject(AiRuntime)` 获取 Runtime。业务工具类也可使用 `@Injectable()`，由类 Provider 或 `providedIn: 'root'` 提供；完整实现见 [tools.ts](examples/tauri-app/src/tools.ts) 和 [main.ts](examples/tauri-app/src/main.ts)。

### 调用上下文与取消

工具方法可接收第二个参数 `ToolContext`，其中包括 `requestId`、`source`、`caller`、`deadline` 和 `signal`。异步方法应响应 `context.signal`，释放等待或外部请求。

应用内调用通过 `AbortSignal` 取消：

```ts
const controller = new AbortController()
const pending = runtime.invoke('math.add', { a: 21, b: 21 }, {
  signal: controller.signal,
})
controller.abort()
await pending.catch((error) => console.log(error.code)) // CANCELLED
```

取消与超时采用协作机制，不能保证业务副作用已回滚；写操作的幂等与回滚由业务方法负责。

## JavaScript API

| Entry | Exports | Description |
| --- | --- | --- |
| `tauri-plugin-ai-api` | `AiRuntime`、`Module`、`Tool`、`defineTool`、`AiError`、`BrowserTransport` 及类型 | 与前端框架无关的工具声明与 Runtime |
| `tauri-plugin-ai-api/tauri` | `TauriTransport` | 桌面 IPC 与 Channel 适配 |
| `tauri-plugin-ai-api/angular` | `provideAiRuntime`、`AngularRuntimeOptions` | Angular DI 与应用生命周期适配 |

| API | Description |
| --- | --- |
| `runtime.registerModule(instance)` | 绑定注解方法及其所属实例 |
| `runtime.register(...tools)` | 注册 `defineTool()` 创建的工具 |
| `runtime.start()` / `runtime.stop()` | 启动、停止 Runtime |
| `runtime.invoke(name, args, { signal? })` | 按完整工具名调用，返回 JSON 结果 |
| `runtime.onEvent(listener)` | 订阅开始、完成、失败事件；返回取消订阅函数 |
| `runtime.tools` | 工具声明视图；启动后为宿主接受的注册快照 |
| `runtime.pendingCount` / `runtime.isStarted` / `runtime.mode` | 在途调用数、启动状态及传输模式 |

完整类型见 [types.ts](guest-js/types.ts)。

## Tool Options

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | 必填 | 模块内工具名；`defineTool()` 使用完整工具名 |
| `description` | `string` | 必填 | 说明工具的用途及输入输出语义 |
| `inputSchema` | `JsonSchema` | 必填 | JSON Schema 2020-12，根类型为 `object` |
| `outputSchema` | `JsonSchema` | 必填 | JSON Schema 2020-12，根类型为 `object` |
| `annotations` | `ToolAnnotations` | `{}` | MCP 工具行为提示 |
| `policy.permissions` | `string[]` | `[]` | 交给宿主 Authorizer 检查的业务权限标识 |
| `policy.timeoutMs` | `number` | `30000` | 调用预算，单位毫秒，最大 `300000` |
| `policy.maxConcurrency` | `number` | `64` | 单工具并发上限，范围 `1–64` |

`annotations` 使用 MCP 标准字段：`readOnlyHint`、`destructiveHint`、`idempotentHint`、`openWorldHint`。它们仅描述行为，不授予权限；`policy` 是框架执行规则，不作为 MCP 工具字段发布。

Schema 仅支持本地引用，关闭 `format` 断言，不进行类型转换或填充默认值。工具名应唯一；完整名称使用字母、数字、下划线、连字符或点号，长度为 `1–128`。

## MCP

使用 `Builder` 显式启用本机 MCP Streamable HTTP 服务：

`src-tauri/src/lib.rs`

```rust
pub fn run() {
    let token = std::env::var("AI_MCP_TOKEN")
        .expect("set AI_MCP_TOKEN before starting the application");

    tauri::Builder::default()
        .plugin(
            tauri_plugin_ai::Builder::new()
                .mcp(tauri_plugin_ai::McpConfig::localhost(38473, token))
                .build(),
        )
        .run(tauri::generate_context!())
        .expect("error while running Tauri application");
}
```

令牌至少包含 32 个 ASCII 字母、数字、连字符或下划线。上述宿主从环境变量读取令牌，可在每次启动时提供同一个值。服务监听 `http://127.0.0.1:38473/mcp`，Client 需发送 `Authorization: Bearer <token>`。前端 Runtime 启动并完成注册后，Client 才能发现和调用工具。

当前提供 `tools/list` 与 `tools/call`，已验证协议版本为 `2025-11-25`。服务只监听本机 IPv4，拒绝带 `Origin` 的请求；尚未提供 OAuth、多用户身份、Resource / Prompt 或工具列表变更通知。

### Rust 宿主策略

`Builder::runtime(RuntimeConfig { ... })` 可设置全局 `max_concurrency`、`max_timeout_ms` 和 `authorizer`。宿主限制可以进一步收紧 Tool policy，Authorizer 同时用于工具发现、应用内调用与 MCP 调用。

非空 `policy.permissions` 未配置 Authorizer 时，工具会被拒绝调用并从发现目录隐藏。JS 的 `beforeCall` 只追加业务检查；纯浏览器调试可使用 `new BrowserTransport({ authorize })`，同步返回 `true` 放行，返回 `false` 或抛错拒绝。

Rust 根据可信入口生成 Caller：IPC 为 `app:<宿主来源>`，本机 MCP 为 `mcp:local`。详细配置与职责边界见 [JS / Rust 框架职责](docs/runtime-responsibilities.md)。

## Default Permission

`ai:default` 不启用任何命令。可信工具执行前端应显式配置 `ai:runtime`。

## Permission Table

`ai:runtime` 包含以下命令权限：

| Identifier | Description |
| --- | --- |
| `ai:allow-runtime-connect` | 注册工具并建立执行通道，由 `runtime.start()` 使用 |
| `ai:allow-runtime-ready` | 确认执行实例就绪，由 `runtime.start()` 使用 |
| `ai:allow-runtime-invoke` | 应用内工具调用，由 `runtime.invoke()` 使用 |
| `ai:allow-runtime-cancel` | 取消在途调用，由调用的 `AbortSignal` 触发 |
| `ai:allow-runtime-resolve` | 返回 JS 执行结果，由执行器内部使用 |
| `ai:allow-runtime-disconnect` | 断开 Runtime，由 `runtime.stop()` 使用 |

对应的 `deny-*` 权限和完整说明见 [Permission Reference](permissions/autogenerated/reference.md)。Tauri capability 控制前端 IPC 访问，MCP 入口另由 Bearer 认证和宿主 Authorizer 控制。

## Runtime Limits

| Item | Limit |
| --- | --- |
| 工具数量 | 每个应用 Runtime 最多 128 个工具 |
| 全局在途调用 | 默认最多 64 个，宿主可进一步限制 |
| 单工具并发 | 默认最多 64 个，可通过 `policy.maxConcurrency` 收紧 |
| 调用超时 | 默认 30 秒，最大 300 秒，宿主可进一步限制 |
| JSON 大小 | 输入、输出及整批工具声明分别限制为 1 MiB |

一个应用绑定一个工具执行实例。超出并发限制直接返回 `BUSY`；断开、取消或超时会终结调用，框架不自动重试业务方法。

## Errors

JS 调用以 `AiError` 返回框架错误，业务方法也可抛出 `new AiError(code, message, details)`。普通异常会被转换为 `HANDLER_ERROR`。MCP 工具执行错误以 `isError` 结果返回；未知工具名属于协议错误。

| Code | Description |
| --- | --- |
| `INVALID_DEFINITION` / `DUPLICATE_TOOL` | 工具声明、Schema 或命名不合法 |
| `INVALID_ARGUMENT` | 输入未通过校验 |
| `INVALID_RESULT` | 方法输出未通过校验 |
| `NOT_READY` | Runtime 未就绪或执行实例已断开 |
| `NOT_FOUND` | 工具不存在 |
| `UNAUTHORIZED` | 未通过宿主权限检查 |
| `BUSY` | Runtime 状态或并发限制不允许当前操作 |
| `TIMEOUT` / `CANCELLED` | 超出调用预算或已取消 |
| `TRANSPORT_ERROR` | Tauri 传输失败 |
| `HANDLER_ERROR` | 工具方法抛出普通异常 |

## Example

[examples/tauri-app](examples/tauri-app) 包含完整的 Angular 工具实验室及 Tauri 桌面宿主，展示注解声明、Schema、调用结果、错误、超时、取消和调用记录。

```sh
cd examples/tauri-app

```

启动脚本自动构建本地 SDK，并启用默认端口为 `38473` 的 MCP 服务。只体验浏览器页面时运行 `yarn dev`，打开 <http://127.0.0.1:1420/>。

示例支持 `.env.local` 固定令牌，并将连接信息保存到应用数据目录的 `mcp-connection.json`。操作步骤见[固定本机 MCP 令牌](examples/tauri-app/README.md#固定本机-mcp-令牌)和[连接 Codex](examples/tauri-app/README.md#连接-codex)。npm 启动、开发服务复用及依赖说明也见[示例 README](examples/tauri-app/README.md)。
